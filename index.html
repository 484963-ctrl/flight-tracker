1. נכנסים ל-github.com/settings/personal-access-tokens/new
2. Token name (שם): flights · Expiration (תוקף): No expiration או שנה
3. Repository access (גישה למאגרים) ← Only select repositories ← flight-tracker
4. Permissions (הרשאות) ← Contents: Read and write, וגם Actions: Read and write
5. Generate token (יצירה), מעתיקים ומדביקים כאן:
